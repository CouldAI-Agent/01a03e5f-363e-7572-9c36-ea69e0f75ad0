# روبوت تحليل السوق الذكي

تطبيق فلاتر مخصص لمراقبة وتحليل أسواق الذهب والبيتكوين بدقة عالية وفي الوقت الفعلي.

## الميزات
*   **تحديثات حية:** يتم جلب أحدث الأسعار للذهب (XAU) والبيتكوين (BTC) وتحديثها تلقائيًا كل دقيقة.
*   **تحليل مبسط ومفصل:** يوفر التطبيق تحليلاً ذكياً يعتمد على تغيرات الأسعار لتقديم توصيات (شراء قوي، احتفاظ، حذر).
*   **واجهة مستخدم عصرية:** تصميم متجاوب يعمل بكفاءة على جميع الشاشات.
*   **دقة البيانات:** يعتمد على واجهات برمجة تطبيقات (APIs) موثوقة مثل CoinGecko و Gold API للحصول على أدق الأسعار.

## التقنيات المستخدمة
*   Flutter & Dart
*   مزود الحالة (Provider)
*   جلب البيانات (HTTP)
*   التصميم المتجاوب (Responsive Design)

## التشغيل
1.  قم بتثبيت الحزم: `flutter pub get`
2.  شغل التطبيق: `flutter run`
